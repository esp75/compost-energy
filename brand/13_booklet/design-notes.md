# Booklet design notes

- Layout: alternating full-bleed bands; Night for the mark, colour and shape sections, Mist for reading (strategy, voice, type, templates). One band = one A4 landscape page in print.
- Type: Instrument Sans for everything readable, Geist Mono labels, Unbounded only for figures. The wordmark appears as the vector SVG, never typeset.
- Imagery: the ring artwork plus a static canvas contour field and particles on the cover; no photography.
- Single committed look (hybrid bands with explicit colours), so the page ignores the viewer's light/dark setting by design.
- Review (fresh-eyes pass in place of claude-taste, which is not installed): checked cover hierarchy, contrast of every text pair, page breaks in the PDF, and that no figure lacks a source tag. Fixed before publishing: none outstanding. P3: the light ring keeps a faint grey halo on Mist (accepted, documented in 00_review.md).
